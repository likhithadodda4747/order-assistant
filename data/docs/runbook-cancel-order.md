# Runbook > Cancel an order

## Before it ships
Orders in `PROCESSING` or `PAYMENT_PENDING` can be cancelled immediately. Any authorized payment is released within 3–5 business days.

## After it ships
Orders in `SHIPPED` cannot be cancelled. The customer can refuse delivery or start a return after delivery.

## Delivered orders
Use the returns process instead of cancellation.
