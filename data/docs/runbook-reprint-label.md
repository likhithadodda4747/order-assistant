# Runbook > Reprint a shipping label

1. Open the order in the fulfillment screen.
2. Select **Shipping > Reprint label**. Labels can be reprinted up to **3 times** per package.
3. If the label printer is offline, restart it and check the paper roll.
4. If the reprint limit is reached, contact the fulfillment lead to void and recreate the shipment.
