# FAQ > What does each order status mean?

- **PROCESSING:** payment confirmed, the order is being picked and packed.
- **PAYMENT_PENDING:** the payment has not completed yet (see the error code, if any).
- **SHIPPED:** the package has left the warehouse; tracking is available.
- **DELIVERED:** the carrier confirmed delivery.
- **CANCELLED:** the order was cancelled and any payment released.
