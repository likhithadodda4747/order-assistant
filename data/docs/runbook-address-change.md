# Runbook > Change the delivery address

1. Address changes are allowed only while the order is in `PROCESSING` or `PAYMENT_PENDING`.
2. Verify the customer's identity before changing the address.
3. Once an order is `SHIPPED`, the address cannot be changed; the customer can redirect the package through the carrier's website.
